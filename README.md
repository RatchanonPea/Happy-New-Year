# 🎆 จับฉลากปีใหม่ (New Year Lucky Draw)

เว็บจับฉลากด้วยวงล้อสำหรับงานเลี้ยงปีใหม่ พร้อมการ์ดอวยพรประกาศผล ใช้ได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และมือถือ
ไม่มีหลังบ้าน ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของผู้ใช้ (localStorage)

## ฟีเจอร์

- **ฉากเปิดเรื่อง** ม่านเวทีเลื่อนเปิด มีกวางกับเอลฟ์มาช่วยดึงม่าน กล่องของขวัญให้แตะเปิด แล้วลูกโป่งลอยขึ้น (มีปุ่ม "ข้าม")
- **จับฉลากด้วยวงล้อ** วงล้อหมุนแล้วหยุดที่ผู้ชนะ มีไฟวิ่งรอบวงล้อที่ช้าลงตามความเร็วจริง เข็มสะบัดทุกครั้งที่ผ่านช่อง
  - โหมด "ไม่จับซ้ำคนเดิม" คนที่ถูกเลือกแล้วจะถูกตัดออกจากวงล้อ
  - รายชื่อเกิน 24 คนจะใช้การ์ดวนชื่อแทนวงล้อ
- **จัดการรายชื่อและเลข**
  - เพิ่มทีละคน หรือนำเข้าหลายรายชื่อ (วางข้อความ หรือไฟล์ `.csv` / `.txt`)
  - เว้นเลขว่างไว้ ระบบรันเลขต่อให้อัตโนมัติ
  - แก้ชื่อและเลขได้ ถ้าเลขซ้ำกับคนอื่นจะสลับเลขกันให้ และเรียงรายการตามเลขใหม่
  - ลากที่จับ `⋮⋮` ไปวางบนอีกแถวเพื่อสลับเลข (เมาส์)
  - ปุ่ม "รันเลขใหม่ 1–n"
- **จอแสดงผลเต็มจอ** สำหรับฉายขึ้นจอใหญ่
- **รองรับมือถือ** แท็บล่างสองแท็บ (จับฉลาก / รายชื่อ) ปุ่มจับติดล่างจอ และมือถือแนวนอน
- **ลดการเคลื่อนไหว** ปิดแอนิเมชันอัตโนมัติถ้าระบบตั้ง `prefers-reduced-motion`

## เริ่มใช้งาน

ต้องมี [Node.js](https://nodejs.org) 18 ขึ้นไป

```bash
npm install
npm run dev        # เปิดที่ http://localhost:5173
```

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm run dev` | เซิร์ฟเวอร์พัฒนา |
| `npm run build` | สร้างไฟล์สำหรับใช้งานจริงในโฟลเดอร์ `dist/` |
| `npm run preview` | ดูตัวอย่างไฟล์ที่ build แล้ว |
| `npm test` | รันเทสต์ทั้งหมด (Vitest) |

## รูปแบบรายชื่อที่นำเข้าได้

หนึ่งบรรทัดต่อหนึ่งคน ใช้ตัวคั่น `,` `;` `|` หรือแท็บ และเลขจะอยู่ก่อนหรือหลังชื่อก็ได้ รองรับเลขไทย

```
สมชาย ใจดี, 12
สมหญิง รักสุข, 7
มานะ
25
```

บรรทัดที่ไม่มีเลขจะถูกรันเลขให้ต่อจากเลขมากสุดในรายการ

## ปุ่มลัดในจอแสดงผลเต็มจอ

| ปุ่ม | ทำอะไร |
| --- | --- |
| `Space` / `Enter` / คลิก | จับฉลาก |
| `F` | สลับเต็มจอ |
| `Esc` | ออกจากจอแสดงผล |

## โครงสร้างโปรเจกต์

```
src/
  App.jsx               สลับหน้า (กล่องของขวัญ / จัดการ / จอแสดงผล)
  components/
    GiftScene.jsx       ฉากม่านและกล่องของขวัญ
    Manage.jsx          หน้าจัดการและจับฉลาก (แท็บบนมือถือ)
    ListPanel.jsx       รายชื่อ แก้ไข ลากสลับเลข
    Wheel.jsx           วงล้อ ไฟวิ่ง เข็ม
    WishCard.jsx        การ์ดประกาศผล
    Display.jsx         จอแสดงผลเต็มจอ
    Backdrop.jsx        ฉากหลัง ดาว พลุ โคมลอย
    ConfirmDialog.jsx   กล่องยืนยัน (แทน confirm ของเบราว์เซอร์)
  hooks/
    useDraw.js          ตรรกะจับฉลากและแอนิเมชัน
    useAppState.js      state และการเก็บลง localStorage
  lib/                  ตรรกะล้วน ไม่แตะ DOM (มีเทสต์ครอบ)
    entries.js          แปลงข้อความเป็นรายชื่อ รันเลข สลับ เรียง สุ่ม
    wheel.js            เรขาคณิตของวงล้อ
    year.js             ปีในคำอวยพร
```

## หมายเหตุ

- **ปีในคำอวยพร** คำนวณจากวันที่ของเครื่อง: เดือน พ.ย.–ธ.ค. ใช้ปีถัดไป เดือน ม.ค.–ต.ค. ใช้ปีปัจจุบัน
- **ข้อมูลอยู่ในเบราว์เซอร์** เปลี่ยนเครื่องหรือล้างข้อมูลเว็บแล้วรายชื่อจะหาย ถ้าจะใช้ซ้ำให้นำเข้าใหม่จากไฟล์
- **ฟอนต์** โหลดจาก Google Fonts (Mitr, Sarabun) ถ้าออฟไลน์จะใช้ฟอนต์สำรอง
- การสุ่มใช้ `crypto.getRandomValues` ให้โอกาสเท่ากันทุกคน
